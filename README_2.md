# Пять звёзд — сайт автосервиса

Сайт автосервиса «Пять звёзд» (Тутаевский муниципальный округ, Ярославская область). Чистые HTML, CSS и JavaScript — без сборщиков и платных библиотек. Репозиторий исторически называется AUTOFiX.

## Структура

```
AUTOFiX/
├── index.html      — разметка страницы
├── style.css       — стили (цвета и размеры — в блоке :root вверху)
├── script.js       — меню, шапка, вход/регистрация, заявка и личный кабинет (Supabase)
├── README.md
└── assets/images/  — фотографии сайта (кладёт владелец)
```

## Фотографии

Положите JPG в `assets/images/` с точно такими именами. Пока файла нет, на его месте показывается нейтральная заглушка с подписью; когда файл появится, он автоматически закроет заглушку — HTML менять не нужно. В `index.html` рядом с каждым `<img>` есть комментарий «ФОТО: …».

| Файл | Где используется |
| --- | --- |
| `hero.jpg` | главный экран (горизонтальное, от 1920×1080) |
| `workshop.jpg` | галерея, крупный кадр (от 1200×800) |
| `gallery-1.jpg`, `gallery-2.jpg`, `gallery-3.jpg` | галерея |
| `body-repair.jpg` | услуга «Кузовной ремонт» (16:10) |
| `accident-recovery.jpg` | услуга «Восстановление после ДТП» (16:10) |
| `diagnostics.jpg` | услуга «Компьютерная диагностика» (16:10) |
| `maintenance.jpg` | услуга «Техническое обслуживание» (16:10) |
| `units-repair.jpg` | услуга «Ремонт узлов и агрегатов» (16:10), см. ниже |
| `parts.jpg` | услуга «Подбор и замена запчастей» (16:10), см. ниже |

Сжимайте снимки (до ~300 КБ), чтобы сайт грузился быстро. Пока файла нет, браузер всё равно запрашивает его и получает 404 — в Network/Console разработчика это видно, посетителю нет. После загрузки фото запрос исчезает.

Старые имена `service-repair.jpg`, `service-diagnostics.jpg`, `service-maintenance.jpg` и `gallery-4.jpg` больше не используются. Если вы уже загружали такие файлы, переименуйте их (`service-repair.jpg` → `body-repair.jpg`, `service-diagnostics.jpg` → `diagnostics.jpg`, `service-maintenance.jpg` → `maintenance.jpg`).

## Что нужно заполнить и проверить

- **Контакты** (`index.html`, блок «Контакты»): точный адрес, график работы, почта, карта или ссылка на маршрут. Места помечены комментариями `TODO` и классом `contacts__todo`.
- **Услуги.** «Ремонт узлов и агрегатов» и «Подбор и замена запчастей» помечены «Уточняйте по телефону» и не подтверждены владельцем. Оставьте и удалите метку, если услуга оказывается, или удалите карточку.
- **Преимущества** (`#advantages`) — редактируемый блок. Добавляйте стаж, гарантии, сертификаты и оборудование только после подтверждения владельцем.
- **Рейтинг.** Оценка 4,4 из 5 (36 отзывов) на сайте не показана: сначала проверьте актуальное значение.
- **Услуги в форме.** Значения `repair`, `diagnostics`, `maintenance` используются в базе и в `script.js` (подписи в кабинете). Менять можно только видимый текст.

## Запуск

Откройте `index.html` в браузере.

## Заявки и вход (Supabase)

- Форма записи пишет в таблицу `public."AUTOFiX"`. Заявку может отправить только вошедший пользователь: `user_id` берётся из Supabase Auth, а не из формы. Защиту обеспечивает политика RLS на INSERT с проверкой `auth.uid() = user_id`.
- `SUPABASE_URL` и публичный (publishable) ключ указаны в блоке Supabase в начале `script.js`. Секретные ключи (`service_role`) в клиентский код помещать нельзя.
- Вход и регистрация — Supabase Auth (email и пароль); сессия переживает обновление страницы. Адрес сайта должен быть в списке Redirect URLs проекта Supabase (письмо с подтверждением email возвращает на него).
- Названия таблицы `AUTOFiX` и функций `autofix_*` — это имена в базе. Не переименовывайте их вместе с сайтом.

## Личный кабинет «Мои заявки»

Раздел появляется после входа. Он читает заявки из `AUTOFiX`, заказы из `autofix_repair_orders`, сметы из `autofix_estimate_versions` (без черновиков), позиции из `autofix_estimate_items` и события из `autofix_order_events` (только `visible_to_customer = true`). Решение по смете принимается только через функцию `autofix_decide_estimate` (`approve` или `reject`).
