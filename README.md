# Админ-панель «Пять звёзд»

## Состав
- `admin.html` — интерфейс панели.
- `admin.css` — оформление в фирменном стиле AUTOFiX / «Пять звёзд».
- `admin.js` — авторизация, проверка роли, чтение данных и рабочие RPC-действия.

## Установка в репозиторий
1. Скопируйте эти три файла в корень репозитория `svarka76/AUTOFiX` рядом с `index.html`, `style.css` и `script.js`.
2. Опубликуйте изменения в GitHub Pages.
3. Откройте `https://svarka76.github.io/AUTOFiX/admin.html`.
4. Войдите учётной записью, у которой в `public.autofix_profiles` значение `role = 'admin'`.

## Безопасность и интеграция
- Используется тот же Supabase URL и только публичный publishable/anon key из клиентского приложения. `service_role` ключ не нужен и не должен добавляться в браузерный код.
- После входа приложение дополнительно проверяет роль `admin`; остальные роли не допускаются.
- Операции приёма заявки, создания сметы, добавления строк сметы, отправки сметы, начала и завершения ремонта вызывают существующие RPC-функции `autofix_accept_request`, `autofix_new_estimate_version`, `autofix_add_estimate_item`, `autofix_send_estimate`, `autofix_start_repair`, `autofix_complete_order`.
- Доступ к таблицам по-прежнему должен ограничиваться существующими RLS-политиками Supabase. Эта панель не заменяет RLS.
- Схема, таблицы и данные базы не меняются.

## Проверки
- `node --check admin.js` — проверка синтаксиса JavaScript.
- HTML разобран стандартным HTML parser.
- Полный live-тест авторизации и RPC требует запуска на опубликованном сайте и входа действующей учётной записью администратора.
