AUTOFiX

Сайт автомобильного сервиса. Чистые HTML, CSS и JavaScript — без сборщиков и платных библиотек.

Структура

AUTOFiX/
├── index.html      — разметка страницы
├── style.css       — стили (цвета и размеры — в блоке :root вверху)
├── script.js       — меню, поведение шапки, отправка заявки в Supabase
├── README.md
└── assets/images/  — изображения сайта

Заявки (Supabase)

Форма «Заявка на сервис» пишет в таблицу public.AUTOFiX. В начале блока 5 в script.js указаны SUPABASE_URL и публичный ключ. Заявку может отправить только вошедший пользователь: user_id берётся из Supabase Auth, а не из формы. Защиту обеспечивает политика RLS на INSERT с проверкой auth.uid() = user_id.

В шапке есть вход и регистрация через Supabase Auth (email и пароль). Сессия сохраняется в браузере и переживает обновление страницы.

Что заменить

Телефон, адрес и почту в блоке «Контакты» в index.html — сейчас там заглушки.

Дальше

Личный кабинет «Мои заявки» (раздел появляется после входа). Он читает заявки из `AUTOFiX`, заказы из `autofix_repair_orders`, сметы из `autofix_estimate_versions` (без черновиков), позиции из `autofix_estimate_items` и события из `autofix_order_events` (только `visible_to_customer = true`). Решение по смете принимается только через функцию `autofix_decide_estimate` (`approve` или `reject`). Админка для мастера и администратора — на следующем этапе.
